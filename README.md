# 💪 مدربك الشخصي (Gym App)

تطبيق ويب عربي يشتغل كمدرب جيم شخصي — حديد، كارديو، وجري.

## المميزات
- **البرنامج**: يعمل برنامج أسبوعي حسب السن، الوزن، الهدف، المستوى، عدد الأيام، والمكان (جيم/بيت) + السعرات والبروتين.
- **التمارين**: مكتبة تمارين لكل عضلة مع طريقة الأداء الصح.
- **الجري والكارديو**: شرح أنواع الجري (Easy, Tempo, Intervals, Fartlek, Long, Hills, Strides) وأنواع الكارديو (LISS, HIIT, Tabata) وبرنامج من الصفر لـ 5 كم.
- **أدوات**: حاسبة مناطق النبض (Zones) وحاسبة سرعة الجري (Pace) وتوقع أزمنة السباقات.
- **السجل**: تسجيل التمارين وإحصائيات الأسبوع (محفوظة على الجهاز).
- **المدرب**: أسئلة وأجوبة سريعة.

## التشغيل
افتح `index.html` في المتصفح — مفيش حاجة محتاجة تتسطب.
